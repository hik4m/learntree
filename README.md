- ➖ Hapus barang dari keranjang
- 👁️ Lihat semua barang

### 2️⃣ **Praktikum 4** (`praktikum4.py`) - Menu Utama

- Database buku dengan Tuple
- Search dan filter buku
- List Comprehension

- Input nilai siswa
- Hitung rata-rata, tertinggi, terendah
- Ranking 3 teratas
- Jumlah yang lulus

## 📝 **Notes & Tips**

> 💭 **Tips Coding:**
> - Selalu beri comment di setiap fungsi penting
> - Gunakan variable names yang deskriptif
> - Test program dengan berbagai input
> - Jangan takut untuk refactor kode
> - Dokumentasi adalah teman terbaik

> ⚠️ **Common Issues:**
> - Pastikan Python sudah terinstall dengan benar
> - File encoding harus UTF-8 jika ada karakter special
> - Perhatikan indentation di Python (sangat penting!)
